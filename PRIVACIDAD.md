# AUTONOMON / El Atajo — Privacy Policy · Política de privacidad

Last updated / Última actualización: September 29, 2026

AUTONOMON is a private, self-hosted automation used **only by its owner** (Luis M. Vargas Rivera) to manage his own YouTube channel **ELATAJO** and his personal Google account. It has no other users.

## YouTube API Services

- This application **uses YouTube API Services**.
- By using this application you agree to be bound by the **YouTube Terms of Service**: https://www.youtube.com/t/terms
- Google's Privacy Policy applies to the data handled through YouTube API Services: **Google Privacy Policy**: http://www.google.com/policies/privacy

## What data is accessed

With the owner's explicit authorization (OAuth 2.0), the application:

- **YouTube:** uploads videos created by the owner to his own channel (title, description, tags, scheduled publish time) and reads his own channel statistics (views, subscribers, likes) for a private weekly report.
- **Gmail / Google Calendar:** reads and sends the owner's emails and reads/creates his calendar events to show them to him on Telegram.

## How data is used, stored and shared

- Data is processed only on the owner's private server and delivered only to the owner (via his private Telegram chat).
- Data is **not sold, not shared with third parties and not used for advertising**.
- Channel statistics are kept only as the previous week's numbers to compare in the weekly report, and are overwritten every week (never stored longer than 30 days).
- No cookies or tracking technologies are used, and no data is collected from any other person.
- Third-party processors: the owner's personal assistant uses the OpenAI API to read/summarize his own emails and calendar for him; video scripts are written with the Google Gemini API; stock footage comes from Pexels and videos are rendered on GitHub Actions. No YouTube user data is sent to these services.

## Deletion and revoking access

- The owner can revoke this application's access at any time in the Google security settings: https://security.google.com/settings/security/permissions
- When access is revoked, or on request, all stored API data is deleted from the server within 7 days.
