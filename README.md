# El Atajo · Render gratis

Crea los Shorts verticales (1080×1920) **sin marca de agua y sin pagar**:

- **Voz:** Kokoro TTS (modelo abierto de Hugging Face) · respaldo: edge-tts
- **Video:** FFmpeg (clips y fotos de Pexels, con zoom suave)
- **Subtítulos:** palabra por palabra, en amarillo

n8n lo activa solo (evento `render`). Para probarlo a mano: pestaña **Actions → Crear Short → Run workflow**.
Cada video queda en **Releases** con un link público.
